# Pratiksha Fandade — Developer Portfolio

A recruiter-focused portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown by Vite, usually:

http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

## Before deploying

1. Your Gmail, LinkedIn and GitHub links are already configured in `src/App.jsx`.
2. Put your resume at `public/resume.pdf`.
3. Replace the placeholder demo links with live project URLs.
4. Add project screenshots or demo videos if available.
5. Review all project descriptions and achievements for accuracy.

## Deploy

This project can be deployed to Vercel, Netlify, or GitHub Pages.
